# Career Roadmaps and Resume Builder

Updated 10 October 2026.

Career Roadmaps replaces Entrepreneurship in the five main dashboard blocks. It contains 15 curated role paths, alias search, ordered learning steps, linked foundation playlists and official guides, language filters, and private progress. The course Explore Tech Roles tab uses the same paths. These are starting guides, not a promise to cover every IT role or every advanced topic in a playlist. React and Android resources include explicit age/coverage notes.

Resume Builder replaces Service Studio in the main navigation. It provides editable personal details, target role, LinkedIn, GitHub, portfolio, education, experience, projects, skills, certificates and achievements. Students can import their portfolio projects, reorder or hide sections, undo a removed entry, and see a live preview. Print / save PDF opens the browser print flow with an isolated A4 document. Choose Save as PDF and disable browser headers and footers. The visual follows the user's white-page reference with centred name and ruled sections.

Resume drafts and career progress use the existing versioned private account state. They are excluded from public portfolios. The server bounds fields and entry counts; old clients cannot silently remove the new data by omitting these fields. Existing help requests remain accessible through Settings. Existing signup welcome and membership card are preserved.

Sources for learning order include MDN Learn (https://developer.mozilla.org/en-US/docs/Learn_web_development), React Learn (https://react.dev/learn), Node Learn (https://nodejs.org/learn/getting-started/introduction-to-nodejs), Android training (https://developer.android.com/courses), and role-specific guides at https://roadmap.sh/roadmaps/. Each step links its relevant guide. Existing course playlist catalogues are reused, with Hindi React, Django and legacy Java Android foundation playlists added.

Validation: account/API SQLite tests, student DOM tests, signup welcome tests, admin DOM tests and Worker adapter tests passed. Browser preview used fictional student data and checked desktop and 390px layouts. The isolated print document was inspected; a saved native PDF was not verified. These local checks do not constitute an authenticated production account test.
